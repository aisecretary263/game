# mini-breakout

ブラウザでそのまま遊べる、Canvas製のシンプルなブロック崩しです。  
外部ライブラリは使っておらず、`index.html` 単体で動作します。

## 起動方法

1. このリポジトリを開く
2. ルート直下の `index.html` をブラウザで開く

> GitHub Pages で公開する場合も、相対パスのみを使っているためそのまま配置できます。

## 操作方法

- `←` / `→`: パドルを左右に移動
- `Space`: ゲーム開始 / 一時停止 / 再開
- `R`: リスタート

## 仕様

- ライフ: 3
- スコア表示あり
- ステージ: 2面（ブロック配置と耐久値パターンが異なる）
- ゲームオーバー / クリア時にオーバーレイ演出あり

## 主要処理の概要

- **ゲームループ**: `requestAnimationFrame` で毎フレーム `update(dt)` と `draw()` を呼び、`dt` 上限を設けて挙動を安定化。
- **当たり判定**: 円（ボール）と矩形（パドル/ブロック）の最近接点を使う判定を実施。衝突法線（X/Y）を推定して反射方向を切り替えることで、不自然なめり込みや反射崩れを抑制。
- **入力処理**: `keydown` / `keyup` で左右キー状態を保持し、毎フレーム移動。`Space` で開始・停止、`R` で初期化。
