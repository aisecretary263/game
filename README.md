# mini-breakout

ブラウザで遊べる、Canvas製のシンプルなブロック崩しゲームです。外部ライブラリは使っていません。

## 起動方法

1. このリポジトリの `index.html` をブラウザで開くだけで起動します。
2. ローカルサーバーは不要です（GitHub Pages でもそのまま公開可能な相対パス構成）。

## 操作方法

- `←` / `→` : パドル移動
- `Space` : 開始 / 一時停止
- `R` : リスタート

## ゲーム仕様

- ライフは 3
- スコア表示あり
- 2ステージ以上（本実装は2ステージ）
- ボール反射は自然になるように調整済み
- ゲームオーバー / クリア演出あり

## 実装の要点（主要処理）

- **ゲームループ**
  - `requestAnimationFrame(loop)` で毎フレーム更新。
  - `update(dt)` で入力・物理を進め、`render()` で描画。
  - 急なフレーム落ちでも破綻しにくいよう、物理は `physicsStep` に分割して逐次計算。

- **当たり判定**
  - パドル衝突では、接触位置に応じて反射角を変化させることで操作感を向上。
  - ブロック衝突では、最短の重なり方向（左右上下）を使って反射方向を決定し、めり込みを防止。

- **入力処理**
  - `keydown` / `keyup` で左右移動フラグを管理。
  - `Space` で開始・一時停止の切り替え。
  - `R` でゲーム状態（スコア・ライフ・ステージ）を初期化して再開可能。
