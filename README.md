# bomb-grid-game

ブラウザで動く、1面構成のオリジナル・ボム置きグリッドアクションゲームです。`index.html` 単体（外部ライブラリなし、Canvas + 素の JavaScript）で動作します。

## 起動方法

1. このリポジトリの `index.html` をブラウザで開く。
   - 例: ファイルをダブルクリック
   - または簡易サーバーを使う場合: `python3 -m http.server` 実行後 `http://localhost:8000` を開く

## 操作方法

- **矢印キー**: プレイヤー移動
- **スペースキー**: 爆弾を設置（同時に最大2個）
- **Rキー**: リスタート

## ルール

- 爆弾は設置後 **2秒** で爆発。
- 爆風は十字方向に **半径2マス**。
  - 壁で止まる
  - ブロックは破壊され、そこで止まる
- 爆風表示は **0.3秒**。
- 爆風や敵接触でミス（ライフ3）。
- 敵1体を爆風で倒すと **CLEAR**。
- ライフが0になると **GAME OVER**。

## 著作権配慮

既存ゲームの画像・音・キャラクター名は使用せず、図形と自作の色分けのみで表現しています。
